# Sales Analysis Java Project
*   **Project description:** To build a Java program that analyzes monthly sales data for a company that sells computers.
*   **How to compile and run the program:** You can run this program through your computer's terminal or in IntelliJ IDEA, where it was designed.
*   **Program output:** The Program will print out the highest total sales change in the dataset in a given time frame (month to month).
*   **Limitations:** All data used is hardcoded within the arrays, and for any ties, the program will choose the first available period instead of the latter.
